# Changelog

All notable changes to this module will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0]

### Added

- PTZ - Set Zoom Lock action. _Note: this only applies locally, and will not affect other controllers_
- Feedback and variables for outdoor camera features, such as Wiper, Defog, and Heater

### Fixed

- Tally mod no functioning correctly on outdoor camera models
- Incorrect substream framerate variable when mode was set to "Follow Output"
- Volume handling to accommodate both % and dB units

## [1.0.0]

### Added

- Initial release of the module
